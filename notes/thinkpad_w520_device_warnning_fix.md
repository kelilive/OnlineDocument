# Thinkpad W520 Device Warnning Fix

* **Unknow Driver** Warnning
  * Install *Intel Management Engine Interface 7.1*

* **WD SES** Warnning
  * Install *WD SES Driver 4.55*

* Click DVD drive then throw **RunDLL** exception about **PWMTR32V.DLL**
  * Install *ThinkPad Power Manager 10.2*
  * You maybe manually copy it to here (*C:\Windows\System32\Lenovo\PowerMgr*)
